# SSU Lecture Downloader

숭실대 LMS(canvas.ssu.ac.kr) 강의를 내려받고 자막을 만들어 주는 데스크톱 앱입니다.

## 할 수 있는 것

- 강의 영상(MP4) 다운로드. 여러 개를 골라 한 번에 받을 수 있습니다.
- 영상에서 음성(MP3) 추출
- 음성을 글로 옮긴 자막(TXT) 만들기. 배포된 앱은 따로 띄운 자막 서버(원격 자막 서버)가 있어야 합니다. 앱이 직접 만드는 방식은 Apple 실리콘 Mac에서 소스로 실행할 때만 됩니다.
- 안 본 강의를 순서대로 자동 재생. 앱 안의 작은 창이나 Chrome 창에서 재생합니다.
- 영상, 과제, 퀴즈 마감 알림. 마감 하루 전과 3시간 전에 알려 줍니다.
- 성적 보기(u-SAINT). 처음 쓸 때 동의 화면이 나옵니다.

## 설치

macOS만 지원합니다. Intel Mac용으로 빌드되고, Apple 실리콘 Mac에서는 Rosetta로 실행됩니다. Windows는 준비 중입니다.

설치 파일은 [GitHub Releases](https://github.com/cafitac/ssu-lecture-downloader/releases/latest)에서 받습니다. DMG를 열어 앱을 응용 프로그램(/Applications) 폴더로 옮기세요. 직접 빌드하려면 아래 개발 항목을 보세요.

앱에 서명이 없어서 처음 열 때 "확인되지 않은 개발자" 경고가 뜹니다. 아래 둘 중 하나로 열면 됩니다.

- 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다.
- 터미널에서 아래 명령을 한 번 실행합니다.

```bash
xattr -dr com.apple.quarantine "/Applications/SSU Lecture Downloader.app"
```

한 번 설치한 뒤에는 새 버전이 나오면 앱 위쪽에 "새 버전" 표시가 뜨고, 원할 때 앱 안에서 업데이트할 수 있어요. 앱이 응용 프로그램 폴더 밖에 있으면 업데이트가 되지 않을 수 있어요.

배포된 앱은 Intel 빌드라서 Rosetta로 돌려도 자막 엔진을 쓸 수 없습니다. 설정의 "원격 자막 서버"를 지정해야 자막이 만들어집니다. 자세한 내용은 [docs/stt.md](docs/stt.md)에 있습니다.

## 쓰기 전에

- 본인 계정으로만, 개인 학습용으로만 쓰세요. 내려받은 강의 영상과 자막을 다른 사람에게 나눠 주면 안 됩니다.
- 학번과 비밀번호는 앱이 켜져 있는 동안 메모리에만 있습니다. 파일이나 키체인에 저장하지 않고, 로그아웃하거나 앱을 끄면 사라집니다.
- 성적은 메모리에만 30분 보관합니다. 디스크에 남는 것은 성적 보기에 동의했다는 기록뿐입니다.
- 마감 알림은 기본으로 켜져 있습니다. 마감 목록(과목 이름, 항목 제목, 마감 시각)은 앱 데이터 폴더에 저장되고, 알림이 켜져 있으면 앱이 꺼져 있어도 알림을 보내려고 백그라운드 작업(LaunchAgent)을 등록합니다. 설정에서 끌 수 있습니다.

## 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| 처음 열 때 "확인되지 않은 개발자" 경고 | 위 설치 항목의 방법으로 엽니다. |
| "앱을 시작하지 못했어요" | `다시 시도`를 누릅니다. 안 되면 앱을 끄고 다시 열고, `~/Library/Logs/com.local.ssu-lecture-downloader/backend.log`를 확인합니다. |
| "로그인이 만료됐어요" | 다시 로그인합니다. 앱을 끄면 로그인 정보가 지워져서 열 때마다 로그인해야 합니다. |
| "파일을 저장하지 못했어요" | 디스크 여유 공간과 저장 폴더를 확인합니다. 설정에서 폴더를 바꿀 수 있습니다. |
| "음성 변환 구성요소를 찾지 못했어요" 또는 자막 구성요소 "설치 필요" | 설정에서 `다시 확인`을 누릅니다. 배포된 앱에서는 `설치` 버튼이 동작하지 않으니 앱을 다시 설치합니다. |
| "이 Mac(Intel)에서는 자막 생성을 지원하지 않아요" | 배포된 앱에서는 정상입니다. 설정의 "원격 자막 서버"를 지정합니다. |
| "Google Chrome을 찾지 못했어요" | 설정의 자동 재생 방식을 "앱 안의 작은 창"으로 바꿉니다. |
| 성적 "u-SAINT에 연결하지 못했어요" | u-SAINT 웹에서 직접 로그인되는지 확인합니다. 비밀번호 오류도 이 문구로 나오고, 로그인이 2번 연달아 실패하면 5분간 다시 시도하지 않습니다. |

화면에 나오는 문구별 설명은 [docs/troubleshooting.md](docs/troubleshooting.md)에 있습니다.

## 개발

Tauri(Rust) 셸 + React/Vite 화면 + Python FastAPI 백엔드로 되어 있습니다. 백엔드는 배포본에서 PyInstaller 사이드카로 앱에 들어갑니다.

```bash
uv sync
cd frontend
npm install
npm run tauri:dev
```

`tauri:dev`가 백엔드도 같이 띄웁니다. 테스트는 루트에서 `uv run pytest -q`, `frontend`에서 `npm run test:contract`, `frontend/src-tauri`에서 `cargo test`입니다.
