# 문제가 생겼을 때

앱이 보여 주는 문구를 기준으로 정리했습니다. 문구가 조금 다르면 비슷한 항목을 찾아보세요. 앱 안에서 원인 코드는 보이지 않고 아래 문장만 보입니다.

## 앱이 켜질 때

**"앱을 준비하고 있어요…"가 오래 간다**
처음 실행할 때는 최대 90초까지 걸릴 수 있다고 화면에 안내가 나옵니다. 90초가 지나도 안 되면 아래 실패 화면으로 바뀝니다.

**"앱을 시작하지 못했어요" / "내부 서버가 켜지지 않았어요"**
앱 안에서 돌아가는 백엔드가 뜨지 못한 경우입니다.

1. 화면의 `다시 시도`를 누릅니다.
2. 그래도 안 되면 앱을 완전히 끄고 다시 엽니다.
3. 화면에 나온 `로그 파일` 경로를 확인합니다. macOS에서는 보통 `~/Library/Logs/com.local.ssu-lecture-downloader/backend.log`입니다. `자세한 오류 보기`를 펼치면 오류 내용도 나옵니다.

앱이 강제 종료된 뒤라면, 다음 실행 때 남아 있던 백엔드를 앱이 알아서 정리합니다. 포트가 겹치면 앱이 다른 포트로 최대 3번 다시 시도합니다.

**처음 열 때 "확인되지 않은 개발자" 경고**
앱에 서명이 없어서 생기는 경고입니다. 해결은 [README](../README.md#설치)에 있습니다.

## 로그인과 LMS 연결

| 보이는 문구 | 할 일 |
|---|---|
| 아이디 또는 비밀번호가 올바르지 않아요. | 학번과 비밀번호를 다시 입력합니다. |
| 로그인을 마치지 못했어요. SmartID 추가 인증이나 비밀번호 변경 안내가 떠 있는지 브라우저에서 확인한 뒤 다시 시도해 주세요. | 브라우저에서 LMS에 직접 로그인해 추가 인증이나 비밀번호 변경 안내를 끝낸 뒤 다시 시도합니다. |
| 숭실 LMS 로그인 방식이 바뀐 것 같아요. 잠시 후 다시 시도하고, 계속되면 앱 업데이트가 필요할 수 있어요. | 잠시 뒤 다시 시도합니다. 계속되면 학교가 로그인 방식을 바꾼 것이니 새 버전을 기다려야 합니다. |
| 로그인이 만료됐어요. 다시 로그인해 주세요. | 다시 로그인합니다. |
| 인터넷 연결이 불안정하거나 숭실 LMS에 닿지 못했어요. 연결을 확인하고 다시 시도해 주세요. | 인터넷과 학교 LMS가 열리는지 확인한 뒤 다시 시도합니다. |
| 숭실 LMS 응답이 너무 늦어요. 잠시 후 다시 시도해 주세요. | 잠시 뒤 다시 시도합니다. |
| 숭실 LMS가 요청을 받아주지 않았어요. 잠시 후 다시 시도해 주세요. | 잠시 뒤 다시 시도합니다. |

앱을 끄면 로그인 정보가 지워지므로, 다시 열면 매번 로그인해야 합니다.

MP4는 받는 중에는 `.part` 파일로 저장되고, 다 받으면 이름이 바뀝니다. 중간에 끊겨도 같은 파일을 다시 받으면 이어 받을 수 있는 경우가 있습니다(서버가 지원할 때만).

## 음성(MP3)과 자막(TXT) 구성요소

음성 변환(ffmpeg)은 앱 안에 들어 있는 것을 쓰고, 컴퓨터에 ffmpeg가 있으면 그것을 먼저 씁니다. 따로 설치하지 않아도 됩니다. 설정의 `음성·자막 구성요소`에서 상태를 볼 수 있습니다(`사용 가능`, `설치 필요`, `지원 안 함`, `확인 중`).

- 설정의 `설치` 버튼은 개발 환경에서만 동작합니다. 배포된 앱에서는 눌러도 설치되지 않고 "현재 실행 중인 배포 앱은 내부 Python 패키지를 안전하게 수정할 수 없습니다. 최신 앱을 다시 설치해 주세요."라고 나옵니다. 이때는 앱을 다시 설치해야 합니다.
- 설치가 실패하면 "구성요소를 설치하지 못했어요. 인터넷 연결을 확인하고 다시 시도해 주세요." 또는 "구성요소 설치가 너무 오래 걸려 멈췄어요. 다시 시도해 주세요."가 나옵니다.
- "음성 변환 구성요소를 찾지 못했어요. 설정에서 확인해 주세요." 가 나오면 설정에서 `다시 확인`을 누르고, 계속 같으면 앱을 다시 설치합니다.
- "변환할 영상 파일을 찾지 못했어요. 먼저 영상을 받아 주세요." 는 영상 파일이 지워졌거나 옮겨진 경우입니다. 영상을 다시 받습니다. MP4를 체크하지 않으면 MP3/TXT를 만든 뒤 원본 영상은 지워집니다.
- "음성을 추출하지 못했어요." 는 영상 파일이 깨졌을 수 있으니 영상을 다시 받습니다.

### 자막

- 배포된 앱은 Intel 빌드이고, Apple 실리콘 Mac에서 Rosetta로 돌려도 앱 안의 자막 엔진(Whisper)을 쓸 수 없습니다. 설정에 "이 Mac(Intel)에서는 자막 생성을 지원하지 않아요. Apple 실리콘 Mac에서 사용할 수 있어요. 설정의 원격 자막 서버를 쓰면 만들 수 있어요."라고 나옵니다. 설정의 `원격 자막 서버`를 지정해야 자막을 만들 수 있습니다. 설정 방법은 [stt.md](stt.md)에 있습니다.
- 앱이 직접 자막을 만드는 것은 Apple 실리콘 Mac에서 소스로 실행할 때만 됩니다. 이 경우 처음 만들 때 Whisper large-v3 모델을 준비하느라 오래 걸릴 수 있다고 설정에 안내가 나옵니다. 배포된 앱에는 해당하지 않습니다. 실패하면 "자막을 만들지 못했어요."가 나오니 연결과 디스크 공간을 확인하고 다시 시도합니다.
- "자막을 만드는 구성요소가 설치되어 있지 않아요. 설정에서 설치해 주세요." 는 위의 `설치` 항목과 같습니다. 배포된 앱에서는 구성요소를 설치할 수 없으니 원격 자막 서버를 씁니다.
- "이미 만들어진 자막 파일이 있어요." 는 같은 이름의 자막이 있다는 뜻입니다. 기존 파일을 옮기거나 지우고 다시 만듭니다.
- "자막 파일을 저장하지 못했어요. 저장 폴더를 확인해 주세요." 는 저장 폴더와 디스크 공간을 확인합니다.

### 원격 자막 서버

설정의 `원격 자막 서버`에서 `연결 확인`을 눌러 먼저 확인하세요.

| 보이는 문구 | 할 일 |
|---|---|
| 원격 자막 서버 주소를 먼저 설정해 주세요. / 서버 주소나 SSH 터널 호스트를 먼저 입력해 주세요. | 설정에 서버 주소나 SSH 터널 호스트를 입력하고 저장합니다. |
| 서버 주소는 http:// 또는 https://로 시작해야 해요. | 주소를 고칩니다. |
| 포트 번호는 1부터 65535 사이여야 해요. | 포트를 고칩니다. |
| 원격 자막 서버에 연결하지 못했어요. 서버가 켜져 있는지, SSH 터널이 열리는지 설정에서 연결 확인을 해 주세요. | 서버가 켜져 있는지 보고 `연결 확인`을 누릅니다. |
| 원격 자막 서버가 시간 안에 응답하지 않았어요. 잠시 뒤 다시 시도해 주세요. | 서버 부하를 확인하고 다시 시도합니다. |
| 원격 자막 서버가 API 키를 받아들이지 않았어요. 설정에서 키를 확인해 주세요. | API 키를 다시 입력합니다. |
| 원격 자막 서버가 오류를 돌려줬어요. 서버 상태를 확인해 주세요. | 서버 쪽 로그를 확인합니다. |
| 원격 자막 서버의 응답을 읽지 못했어요. / 원격 자막 서버가 아무 내용도 돌려주지 않았어요. | 서버 종류(`whisper_cpp_server`, `openai_compatible`)가 맞는지 확인합니다. |
| ssh 실행 파일을 찾지 못했어요. | macOS에 ssh가 있는지 확인합니다. |
| SSH 터널을 열지 못했어요. 호스트 이름과 SSH 키 설정을 확인해 주세요. | 터미널에서 같은 호스트로 `ssh`가 되는지 확인합니다. |
| SSH 터널이 시간 안에 열리지 않았어요. 네트워크와 호스트를 확인해 주세요. | 네트워크와 호스트를 확인합니다. |
| SSH 호스트 이름이 올바르지 않아요. 공백이나 -로 시작하는 이름은 쓸 수 없어요. | 호스트 이름을 고칩니다. |

## 자동 재생

| 보이는 문구 | 할 일 |
|---|---|
| Google Chrome을 찾지 못했어요. 설정의 자동 재생 방식에서 ‘앱 안의 작은 창’을 골라 주세요. | Chrome을 설치하거나, 설정의 `자동 재생 방식`을 `앱 안의 작은 창`으로 바꿉니다. |
| Chrome 창이 열리지 않았어요. / Chrome이 바로 종료됐어요. / Chrome에 연결하지 못했어요. 다시 시도해 주세요. | 다시 시도합니다. 반복되면 `앱 안의 작은 창`으로 바꿉니다. |
| Chrome 창이 닫혀 자동 재생을 멈췄어요. / Chrome과의 연결이 끊겨 자동 재생을 멈췄어요. | 재생 중에 Chrome 창을 닫지 마세요. 다시 시작합니다. |
| Chrome 창이 열려 있지 않아요. | 다시 시작합니다. |
| 이미 자동 재생이 진행 중이에요. | 진행 중인 재생을 끝내거나 `중지`한 뒤 다시 시작합니다. |
| 순서대로 시청할 영상이 없어요. | 안 본 영상이 없는 경우입니다. |
| 재생이 멈춰 건너뛰었어요 | 재생 시간이 일정 시간 안 흐르면 한 번 다시 불러오고, 그래도 안 되면 그 강의를 건너뜁니다. 건너뛴 강의는 따로 봐야 합니다. |

- Chrome 방식에서는 재생이 시작되면 앱 전용 Chrome 창이 최소화됩니다. 화면에 "Chrome 창이 최소화돼 있으면 다시 열어 주세요."가 나오면 `Chrome 창 보이기`를 누르세요. 최소화 중에도 계속 재생되는지는 확인되지 않았습니다.
- 앱 안의 작은 창 방식에서는 창을 가리거나 최소화하면 재생이 멈춥니다. "재생 창이 가려져 있어서 멈춰 있어요. 창을 보이게 해 주세요."가 나오면 `재생 창 보이기`를 누릅니다.
- 앱은 재생만 하고 출석 처리는 학교 플레이어가 합니다. 앱에서 본 것으로 표시돼도 LMS에 반영됐는지는 LMS에서 확인하세요.

## 성적 보기

"지금 가져올 수 없어요" 아래에 이유가 한 줄 나옵니다.

| 보이는 문구 | 할 일 |
|---|---|
| u-SAINT가 로그인을 받지 않았어요. u-SAINT 웹에서 직접 로그인되는지 확인해 주세요. 강의 기능은 그대로 쓸 수 있어요. | u-SAINT 웹에서 같은 학번과 비밀번호로 로그인되는지 먼저 확인합니다. 비밀번호를 바꿨다면 앱에서 로그아웃하고 다시 로그인합니다. |
| u-SAINT에 연결하지 못했어요. 강의 기능은 그대로 쓸 수 있어요. | 네트워크를 확인하고 `다시 시도`를 누릅니다. u-SAINT 점검 중일 수도 있습니다. |
| 로그인 정보를 찾지 못했어요. 앱에 다시 로그인한 뒤 시도해 주세요. | 앱에 다시 로그인합니다. |
| 성적 보기를 켜야 성적을 읽어 올 수 있어요. | 상단 `성적`에서 동의하고 켭니다. |

u-SAINT 로그인이 연달아 2번 실패하면 앱은 5분 동안 그 계정으로 u-SAINT 로그인을 다시 하지 않습니다. 비밀번호가 틀린 채로 계속 시도해서 계정이 잠기는 것을 막기 위해서입니다. 5분을 기다리거나, 앱에서 로그아웃한 뒤 다시 로그인하거나, 설정에서 성적 보기를 `끄기`로 껐다가 다시 켜면 이 기록이 초기화됩니다. 비밀번호가 틀렸다면 먼저 고친 뒤에 하세요.

## 그 밖에

- "문제가 생겼어요. 잠시 후 다시 시도해 주세요." / "앱 안에서 문제가 생겼어요. 다시 시도해 주세요.": 다시 시도하고, 반복되면 앱을 껐다 켭니다. 그래도 같으면 `backend.log`를 확인하거나 이슈로 알려 주세요. 로그에 개인 정보를 붙여 넣지 마세요.
- "앱 서버가 이 기능을 지원하지 않아요. 앱을 다시 시작해 주세요.": 앱을 껐다 켭니다.
- 알림이 안 보이면 설정의 `알림 테스트`를 누르고, 그래도 안 보이면 시스템 설정의 알림에서 이 앱을 허용합니다.
